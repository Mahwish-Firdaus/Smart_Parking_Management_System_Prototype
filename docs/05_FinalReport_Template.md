## Abstract
This project implements a small smart parking workflow in C++17. It models vehicle types and compatible parking slot categories, allocates available slots, records entry and exit, calculates a fee, reports occupancy, searches records and saves state to CSV files. The design uses an abstract vehicle class with derived types, encapsulated parking slots, STL containers, exception handling and modular source files. It is a console simulation; it does not claim to connect to physical sensors or payment systems.
